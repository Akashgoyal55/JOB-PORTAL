# 💼 Job Portal

Job Portal is a full-stack web application that helps users search for jobs, explore opportunities, and manage job-related workflows in one place. 
It is designed to make the job search process easier by providing a user-friendly interface for browsing listings and interacting with application features. 
The platform helps users save time and navigate opportunities more efficiently through secure backend services, database-driven workflows, and responsive frontend experiences.

---

## 📦 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- REST APIs
- JavaScript
- HTML/CSS

---

## 🚀 Features

- Browse and search job listings
- User-friendly frontend workflows
- Secure backend APIs
- Database-driven job and application management
- Scalable and modular full-stack architecture
- End-to-end feature integration

---

## 🛠️ How to Run

- Run `npm install` and `npm start` for the frontend
- Go to the backend folder and run `npm install`
- Start the backend server with the project run command
- Add required environment variables in the `.env` file
- Make sure MongoDB is connected and running
